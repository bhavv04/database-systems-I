# CPS510 - Database Systems I

Assignments covering core relational database concepts, from schema design 
to normalization and full-stack integration.

## Assignments

### A3 - sql-schema-setup
Creating relational tables, sequences, and ER diagrams using Oracle SQL.

### A4 - sql-queries
Writing fundamental SQL queries including SELECT, JOIN, and aggregations.

### A5 - advanced-queries
Complex SQL including nested subqueries, set operations, and advanced joins.

### A6 - functional-dependencies
Analyzing functional dependencies (FDs) and understanding data redundancy.

### A7 - normalization-3nf
Decomposing relations into Third Normal Form (3NF) using the Bernstein algorithm.

### A8 - normalization-bcnf
Decomposing relations into Boyce-Codd Normal Form (BCNF) and comparing 
tradeoffs with 3NF.

### A9 - db-web-app
Building a full-stack web application on top of the course database, 
connecting a Python backend to an Oracle DB with a frontend interface.
